# ⚠️ 本目录已废弃

这是**早期单文件 OCR 版本**（768 行），功能已被独立版完全取代。

## 请使用 → [screen-translator-standalone](https://github.com/soyoung5565/screen-translator-standalone)

| | 旧版（本目录） | 独立版 |
|---|---|---|
| 代码量 | 768 行单文件 | **4,652 行**（模块化 + 6 套测试） |
| 识别方式 | MIMO OCR + 翻译 | **视觉模型直接返回译文 + 坐标** |
| 依赖 | **强依赖 Hermes**（从 `~/.hermes/config.yaml` 读 key） | **零 Agent 框架依赖**，只需自己的 `.env` |
| UI | 基础悬浮窗 | OpenDesign 重设计（状态带 / 分段控件 / 状态灯） |
| 打包 | 无 | PyInstaller exe + `--selftest` 验收闭环 |

## 为什么旧版被取代

1. **强依赖 Hermes** —— 从 `~/.hermes/config.yaml` 读 API Key，脱离 Hermes 环境就完全跑不起来，不适合作为独立工具分发。
2. **依赖 OCR 引擎** —— 旧版走「先 OCR 出文字、再翻译」的链路；独立版直接让视觉模型返回**每行文字 + 坐标**，少一层 OCR 误差，且支持**原位像素级覆盖**（译文贴在原文原位，原文半透可见便于校对）。
3. **工程化差距** —— 独立版有墨迹校正（用截图实测的墨迹包围盒反推真实框，修正模型系统性偏小的 `h/w`）、变化检测、缓存 key 用图片内容哈希、解析器容错、6 套测试、打包自检闭环。
